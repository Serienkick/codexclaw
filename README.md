# 暖伴 · 适老化陪伴小程序原型（CodexClaw）

为独居 / 空巢老人设计的适老化陪伴小程序 **MVP 原型集**。围绕老一天里最核心的三件事展开：

- **容易忘** → 记忆守护（用药 / 喝水 / 散步提醒 + 子女远程留言 + 完成同步）
- **喜欢小娱乐** → 戏曲 / 相声 / 老歌音频馆 + 智能选视频（零选择、语音点播）
- **休息** → 规律作息提醒 + 助眠白噪音

并延伸出：实时安全监听（长时间无活动主动确认、一键报平安）、便民服务（快递代取 / 医师到家 / 叫车 / 买药 / 家政 / 订餐）、以及**子女端远程守护 + 月度会员付费**闭环。

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `elder-standalone.html` | 老人端独立界面（首页 / 提醒 / 娱乐 / 休息 / 安全 / 便民） |
| `child-standalone.html` | 子女端独立界面（看板 / 消息 / 照顾 / 会员） |
| `elder-companion-onboarding.html` | 建档分流与用户分类（`role = elder \| child`） |

| `elder-companion-prototype.html` | 老人端早期原型 |
| `elder-companion-child-prototype.html` | 子女端早期原型 |
| `elder-test-guide.html` | 荆州真实家庭试用指南（任务清单 + 反馈摘要） |

直接用浏览器打开任一 `.html` 即可点击体验。

## 设计要点

- **老人端全程免费、不上功能锁**；功能锁只锁在子女端的增值功能（多联系人 / AI 周报 / 投喂视频 / 多老人 / 硬件联动）。
- **数据库仅开发者后台可见**，普通用户（老人 / 子女）在 App 内看不到原始数据；`users` 集合须经云函数鉴权，敏感字段服务端加密。
- **用户分类（老人 / 子女）是所有功能、权限、付费的总开关**。

## 业务流程

建档分流（老人 / 子女）→ 双端各司其职 → 数据过云端 + 微信订阅消息 → 免费钩子（基础看板 / 异常推送）→ 付费锁（分档 ¥9.9 / ¥19.9 / ¥29.9）→ 充值解锁高级功能 → 续费。

## 后续计划

1. **地基**：微信云开发落地 `users` 集合 + 建档云函数 + 权限规则（后续所有功能的总开关）
2. 老人端 / 子女端小程序真代码
3. 荆州 3–5 个真实家庭内测 → 抖音引流（CodexClaw 群）→ 月度会员变现

## 技术选型

微信小程序 + 微信云开发（CloudBase）+ 微信订阅消息推送。
